## 概要
- この画像のように、1920x1080のウィンドウに600x600のジャケット画像をアーティスト名・曲名を表示するhtmlです。
- デスクトップにhtmlファイルを置いて、ブラウザで開くだけで動作します。
- あとはこのウィンドウを、あなたの環境にあわせて配信してください。

## コントローラー画面
- htmlを開くとこのコントローラー画面になります。
- あらかじめDJで使いそうな曲を最大50曲まで登録しておけます。
- 各曲をクリックすると、フェードと共に画面が切り替わります。
